Homework01 for CIS267: Brick Breaker

How to Play: 
  Use the left arrow key or A to move the paddle to the left. Use the right arrow key or D to move the paddle to the right. 
  Break all of the bricks in the level to beat the game. There is a score system that adds 10 points for each brick broken.
  The player loses when all three lives in the top left corner are gone.

Notes:
-This game starts automatically, there is no menu screen.
-This game is bare bones and the foundation for a fully fleshed out brick breaker game.
-The paddle uses a polygon collider shaped like a trapezoid for simplicity.
-There is no art or unique theme, it can be changed at any time.
-There is no sound effects or music.
